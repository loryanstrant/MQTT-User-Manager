# Product artwork

The account-to-devices icon is original project artwork: one account connected to device nodes. `app/static/icon.png`, `favicon-32.png` and the multi-size `favicon.ico` derive from the same design and are covered by the project MIT license.

The header uses the official GitHub Mark, downloaded from `https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png`, resized without changing its design. GitHub owns that trademark. Its use links to this project's GitHub repository and does not imply GitHub endorsement. See [GitHub's logo guidance](https://github.com/logos).

Product screenshots must use synthetic names and notes. Never include deployment addresses, account secrets, private credential metadata or real device identifiers. Proposal images are not product screenshots.
